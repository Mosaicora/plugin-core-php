# Changelog

All notable changes to the Mosaicora PHP plugin core are documented here.

The project follows [Semantic Versioning](https://semver.org/).

## [1.1.0] - 2026-07-30

### Added

- Added the reusable Mosaicora Open Graph v3 semantic-role catalog.
- Added role type lookup and typed value validation for text, list, boolean,
  and analytics metric values.

### Compatibility

- Existing URL builders, cache helpers, value objects, and JSON-LD builders
  remain backward compatible with version 1.0.

## [1.0.0] - 2026-07-29

### Added

- Initial framework-agnostic Open Graph URL and JSON-LD helpers for PHP 8.1+.
